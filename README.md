# 🌾 AgroSat Pakistan — AI & Satellite Field Analytics

AgroSat Pakistan is a precision agriculture platform designed for rural farmers. It combines Computer Vision AI for crop disease detection, localized Urdu audio feedback, and real-time NASA/Weather satellite field telemetry.

## 🌟 Key Features
- **🍃 AI Leaf Disease Scanner:** Built on PlantVillage dataset (38 diseases, 95%+ accuracy).
- **🎙️ Urdu Voice Assistant:** Audio-guided diagnosis and spray recommendations for low-literacy farmers.
- **🛰️ Satellite Telemetry Data:** Real-time monitoring of Soil Moisture, Soil Temperature, and Rainfall.
- **🗺️ Interactive Field Map:** Dynamic map pin location with localized weather insights.

## 🛠️ Tech Stack
- **Frontend:** HTML5, CSS3, JavaScript, Leaflet.js
- **AI / Speech Model:** PlantVillage Dataset, Web Speech API (Urdu TTS)
- **Telemetry Data:** Open Weather Telemetry / Satellite APIs
